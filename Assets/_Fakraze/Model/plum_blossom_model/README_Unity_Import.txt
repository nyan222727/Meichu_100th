Plum Blossom Unity Model

Files:
- plum_blossom.obj
- plum_blossom.mtl

Unity usage:
1. Drag the whole plum_blossom_model folder into Unity Assets.
2. Select plum_blossom.obj.
3. Drag it into your scene or use it as a prefab.
4. Recommended scale: 0.2 ~ 0.5 for projectile, 1.0 for warning/skill effect.
5. If material colors do not appear, create Unity materials manually:
   - PetalPink: pink
   - CenterYellow: yellow
   - StamenRed: red
6. For projectile usage, add Collider + Rigidbody or use your existing PlumProjectile script.
